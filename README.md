Firmware Highlights

Seamless FPGA Synth Integration: An 8-bit microcontroller acts as a front panel for XVA1/XFM2 synth bitstreams, communicating via MIDI SysEx over UART to control all parameters in real-time.

Preset Librarian with Onboard EEPROM: Stores up to 128 presets on an external I²C EEPROM with automatic self-recovery if data is corrupted or missing — no PC needed.

CV/Expression Inputs & Calibration: Multiple analog CV inputs and an expression pedal jack are mapped to synth parameters with a built-in calibration routine for accurate 1V/oct scaling.

Capacitive Touch User Interface: Touch pads with smart debouncing and an LCD menu system provide intuitive preset selection, parameter tweaks, and system settings.

Intelligent Power Management: Soft-latch power control, brown-out detection, and USB power protection ensure safe startup, shutdown, and data integrity, with a watchdog to handle firmware lockups.
